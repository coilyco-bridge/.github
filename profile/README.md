# coilyco-bridge

GitHub home for `coilyco-bridge`. The canonical source lives on Forgejo.

**[forgejo.coilysiren.me/coilyco-bridge](https://forgejo.coilysiren.me/coilyco-bridge)**

Code, issues, discussions, and CI happen there. This GitHub presence is a name-squat redirect.

## Repositories

- [`coilyco-bridge/.github`](https://github.com/coilyco-bridge/.github) - Organization profile and canonical Forgejo redirect for coilyco-bridge.
- `coilyco-bridge/agentic-os-hardware` - 🔒 _(private repo)_ Hardware and local-LLM knowledge base with device profiles, benchmarks, and model rankings.
- `coilyco-bridge/agentic-os-kai` - 🔒 _(private repo)_ Kai's agent operating context, skill catalog, fleet inventory, and cross-repository automation.
- `coilyco-bridge/agentic-os-xxx` - 🔒 _(private repo)_ Private ComfyUI harness for agent-driven image generation, workflow assets, and reference media.
- `coilyco-bridge/atlas` - 🔒 _(private repo)_ Static architecture site that visualizes repositories and their cross-org dependency graph.
- `coilyco-bridge/deploy` - 🔒 _(private repo)_ Kubernetes deployment monorepo for always-on services across Kai's homelab.
